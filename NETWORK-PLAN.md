# Хвостоград Такси — игра по сети (WebRTC, напрямую между браузерами)

Выбор владельца (24.09.2026): вариант «напрямую между браузерами», без своего сервера.
Работает только на GitHub Pages (https://alexsenchenko.github.io/hvostograd-taxi/) — в артефакте claude.ai WebRTC запрещён,
там сетевой режим скрыть (проверка: `typeof RTCPeerConnection` + неудачное подключение к посреднику).

## Устройство
- Библиотека PeerJS (UMD с cdnjs, точная версия; проверить наличие на cdnjs до вставки) + её бесплатный
  посредник для знакомства (0.peerjs.com) и STUN по умолчанию. TURN нет — у части мобильных сетей подключение
  не получится: через 10 с честно сказать «сеть не пускает, играем одни» и продолжить соло.
- Звезда: создатель комнаты = хозяин, peer id `hvostograd-<КОД>`; гости подключаются к хозяину, хозяин
  пересылает состояния всем. До 6 игроков.
- Код комнаты — слово + число из детского словаря («ЛИСА-42»), вводится кнопками/полем, без открытого лобби.
- Город одинаковый у всех без передачи (сид mulberry32 20260904). Трафик, пешеходы, заказы — у каждого свои.
- Пакет 10 раз/с: {id, x, y, a, sp, color, driver, dirt, hasPax}. У получателя — буфер 100–150 мс и
  интерполяция; такси других игроков = makeTaxi() с их цветом и головой водителя, над ним табличка-имя.
- Имя = имя водителя + число (свободного текста нет). Общения нет, только реакции: «Привет!», «Ура!», гудок.
- Общее: счёт комнаты «вместе развезли N» (хозяин суммирует), на мини-карте — точки друзей.
- Сохранение и награды — локальные, как сейчас (ключ `hvostograd-taxi-3d-v1` не менять).

## Проверка
- Два контекста Playwright на локальном сервере + настоящий посредник PeerJS: оба видят такси друг друга,
  движение плавное, выход гостя убирает его такси, падение хозяина → гостям «комната закрылась», соло продолжается.
- Проверить, открывается ли 0.peerjs.com из Беларуси (дочка/друзья могут быть там) — если нет, это аргумент за
  вариант с посредником на Cloudflare.
- Ручная проверка: два настоящих устройства в разных сетях (Wi-Fi + мобильный интернет).
